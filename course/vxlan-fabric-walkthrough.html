    Reading the records

    What this data can and can't answer

    Flow data can answer

    • Who is using a given spine or underlay link, by tenant, VNI, site or application
    • The full path of a conversation, from branch or internet edge to the server's port
    • Which public address a customer used, by joining edge, firewall NAT and fabric records
    • Whether ECMP is spreading load or a few large flows are piling onto one link
    • Traffic between segments or zones that are supposed to be isolated

    Flow data can't answer

    • Per-packet loss, latency or jitter. Flow counts traffic; it doesn't time it.
    • Anything inside an encrypted tunnel, from the tunnel's own transit links
    • VM-to-VM traffic on the same host, which never reaches a switch port
    • Every short or tiny flow, since sampling can miss them
    • Who the person is, unless VPN, NAC or directory data is added

    This walkthrough records every hop so you can compare vantage points. Real switches sample roughly one packet in a few thousand, routers and firewalls usually export sampled or unsampled IPFIX, and the collector scales and joins it all.
